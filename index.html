技术方案

采用 Python + OpenCV + MediaPipe Hands 框架实现。

Python编写代码串联OpenCV和MediaPipe Hands。通过OpenCV调用电脑摄像头，再将每一帧图像传入MediaPipe Hands模型进行分析。

MediaPipe Hands模型负责检测手部21个关键点的坐标，最后用OpenCV在图像上绘制关键点和连接骨架，将坐标数据反映在电脑屏幕上，形成浅显易懂的骨架结构。

实现思路

1. 安装并导入所需库，初始化 MediaPipe Hands 检测器。

2. 下载并安装 OpenCV，打开摄像头。

3. 调用 MediaPipe Hands 模型检测手部关键点。

4. 通过 OpenCV 显示处理后的视频。
